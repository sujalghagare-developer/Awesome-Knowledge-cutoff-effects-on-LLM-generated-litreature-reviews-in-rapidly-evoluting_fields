# Curated Datasets for LLM Knowledge Cutoff & Hallucination Studies

1. **DefAn Benchmark Dataset**
   - **Source:** MDPI / Information (2025)
   - **Description:** 75,000+ targeted prompts designed to evaluate factual decay and citation hallucinations.
   - **Link:** https://www.mdpi.com/2078-2489/16/11/937

2. **RefChecker Benchmark**
   - **Source:** Amazon Science / EMNLP
   - **Description:** Benchmark dataset for fine-grained claim extraction and citation entailment verification.
   - **Link:** https://github.com/amazon-science/refchecker

3. **Semantic Scholar Academic Graph (S2AG) API**
   - **Source:** Allen Institute for AI
   - **Description:** Live dynamic scholarly API offering real-time paper metadata and citation graphs to bypass static cutoff boundaries.
   - **Link:** https://www.semanticscholar.org/product/api
