# Key Tools and Libraries

1. **LangChain Framework:** Framework for building agentic workflow and dynamic retrieval pipelines. [Link](https://www.langchain.com/)
2. **LlamaIndex:** Specialized data connectors for academic repositories and vector databases. [Link](https://www.llamaindex.ai/)
3. **Crossref REST API:** Standard API for programmatic DOI metadata lookup and citation integrity checking. [Link](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)
4. **FAISS:** Vector similarity search engine for dense retrieval of preprints and scientific papers. [Link](https://github.com/facebookresearch/faiss)
5. **RefLite:** Command-line tool to check generated manuscript DOIs against public scholarly indexes. [Link](https://pypi.org/)
