# Recommended GitHub Implementations

1. **`langchain-ai/langchain`**: Open-source framework for building dynamic RAG applications. [GitHub Link](https://github.com/langchain-ai/langchain)
2. **`amazon-science/refchecker`**: Fine-grained citation and claim auditing toolkit. [GitHub Link](https://github.com/amazon-science/refchecker)
3. **`HKUDS/RAG-Survey`**: Code and benchmark repository for RAG architectures. [GitHub Link](https://github.com/HKUDS/RAG-Survey)
4. **`run-llama/llama_index`**: Data indexing framework connecting live literature databases to LLMs. [GitHub Link](https://github.com/run-llama/llama_index)
5. **`epfml/sentinel-citation`**: Script pipeline for citation verification. [GitHub Link](https://github.com/epfml/sentinel-citation)
